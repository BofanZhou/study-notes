# 第 4 课 · 摩擦(静力学收官)

> [!important] 库仑定律与自锁
> Fs 是**被动力**:平衡时 0 ≤ Fs ≤ fs·FN(取等号仅临界/滑动)。
> 摩擦角 tanφs=fs;**主动力线入摩擦锥 → 自锁(多大力都滑不动)**;斜面不滑条件 α≤φs。

## 考虑摩擦的解题流程

先按无摩擦列平衡 → 补临界条件 Fs=fs·FN → 解出临界值 → **答案通常是范围**。

## 滚动摩阻

Mf ≤ δ·FN(δ 有长度量纲、极小)→ 滚比滑省力的力学本质。

> [!warning] 陷阱
> 摩擦力阻碍**相对滑动趋势**,可以是动力(走路/驱动轮);
> 静止时先由平衡求 Fs,再验证 ≤ 上限,顺序不能反。

> [!tip] 衔接流体力学
> 流体**没有静摩擦力**——"不能抵抗剪切"的另一面;壁面 no-slip 靠黏性而非库仑摩擦。
