经济效果评价指标 NPV · IRR · Payback Period

🎯 本课目标

学完本课(约 25 分钟),你将能够:① 手算一个项目的净现值 NPV 并下结论; ② 说清 IRR 的定义,用线性内插估算它,并知道它的适用边界; ③ 计算静态与动态投资回收期,说出两者的差距从哪来; ④ 判断一个节能改造项目「值不值」。

一、评价指标的三大门派

第 2 课解决了「换算」,这一课解决「判断」。评价指标分三派: 时间型(投资回收期——多久回本)、 价值型(净现值 NPV、净年值 NAV——净赚多少)、 比率型(内部收益率 IRR——盈利效率多高)。 考试与实务里 NPV 与 IRR 是绝对主角,回收期作辅助。

二、净现值 NPV:一锤定音的判据

净现值(net present value, NPV):把项目一生(0 到 n 年) 的净现金流量,按基准收益率 ic 全部折现到 0 点后求和:

NPV = Σt=0n (CI − CO)t · (1 + ic)−t

判据:NPV ≥ 0 → 方案可行。注意 NPV ≥ 0 的含义不是「不亏钱」, 而是「赚回了基准收益率要求的回报之后还有剩」—— 超额部分才是真正意义上的「净赚」(都按 0 点价格计)。

例题:节能改造值不值?

某商场空调系统节能改造:初投资 120 万(t=0),此后每年末省电费 20 万,设备寿命 10 年, 基准收益率 ic = 8%。第 2 课已算过 (P/A, 8%, 10) = 6.7101:

NPV = −120 + 20 × 6.7101 = +14.2 万 → NPV ≥ 0,改造值得做

三、投资回收期:多久回本?

静态投资回收期(static payback period, Pt) 不折现,数「累计净现金流转正」的时刻。上例每年净收益均匀 20 万, 累计到第 6 年恰好 −120 + 20×6 = 0:

Pt = (累计净现金流首次 ≥ 0 的年份 − 1) + |上年累计| / 当年净现金流 = 6 年

判据:Pt ≤ 基准回收期 Pc。它简单直观、天然关注「钱套牢多久」, 但有两个先天缺陷:忽略时间价值、无视回收期之后的现金流 ——长寿的优质项目会被低估。动态投资回收期 (dynamic payback period)把折现引入累计净现金流: 上例折现后累计转正的时刻约为 8.5 年(用 (P/A, 8%, t) = 120/20 = 6 反查 t, t=8 时系数 5.7466、t=9 时 6.2469,插值得 8.5)。 静态 6 年 vs 动态 8.5 年——差距全是时间价值。

四、内部收益率 IRR:项目的「自带收益率」

内部收益率(internal rate of return, IRR): 使 NPV 恰好等于 0 的那个折现率:

Σt=0n (CI − CO)t (1 + IRR)−t = 0　⟹　判据:IRR ≥ ic → 可行

直觉:IRR 是项目「自己长出来的盈利能力」,与外部利率无关——「内部」二字由此而来。 上例:20 × (P/A, IRR, 10) = 120 ⟹ (P/A, IRR, 10) = 6.0,内插得 IRR ≈ 10.6% > 8% ✓, 与 NPV 结论一致。手算用线性内插:找两个折现率 i₁(NPV>0)与 i₂(NPV<0), IRR ≈ i₁ + NPV₁/(NPV₁+|NPV₂|)·(i₂−i₁)。

⚠️ 常见误区

①「NPV < 0 = 项目亏本」✗ 只是没达到基准收益率门槛,项目仍可能在赚钱。
②「IRR 越大方案越好」✗ 互斥方案比选时 IRR 会骗人——第 4 课专门拆它。
③「非常规现金流必有唯一 IRR」✗ 中途有大额追加投资时,NPV–i 曲线可能与横轴多次相交,IRR 多解甚至无解;此时认 NPV。

🔗 连接你的专业

「初投资 + 每年等额收益 + 寿命 n」是暖通节能项目的标准现金流形态(EMC 合同、LED 改造、 高效机房改造全是这个形状),于是有一张必背的快捷公式: NPV = −投资 + 年净收益 × (P/A, ic, n)。 考试里的节能改造题、注册考试的财务评价题,90% 从这一行出发。 另记一个「年金化」工具:净年值 NAV = NPV × (A/P, ic, n)—— 把 0 点的净现值摊成每年的等额净收益,第 4 课比选不同寿命方案时它就是主角。
