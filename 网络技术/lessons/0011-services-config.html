信息服务系统配置 DHCP · DNS · WWW · FTP

🎯 本课目标

学完本课(约 20 分钟),你将能够:

① 按步骤在 Windows Server 上配置 DHCP/DNS/WWW/FTP 服务; ② 认出每种服务的关键配置项与常见错误(综合题"看截图选配置")。

一、配置前的共同动作

服务器先做三件事:静态 IP(服务器地址不能漂)、安装对应角色/服务 (Windows Server 的"添加角色",Linux 下装服务包)、防火墙放行端口 (DHCP 67/68、DNS 53、HTTP 80、FTP 21/20)。客户端验证:DHCP 用 ipconfig /renew、 DNS 用 nslookup、连通用 ping(第 7 课工具链)。

二、DHCP 服务器(综合题最爱)

配置项含义考法
作用域 scope一段可分配的 IP 范围(如 192.168.10.100~200)给需求算范围(第 6 课结合)
排除范围 exclusion作用域内不自动分配的地址(留给打印机/服务器)问"打印机为何还能冲突"→ 没设排除
保留 reservationMAC 绑定固定 IP某主机永远拿同一地址
租约期 lease地址可用时长,默认 8 天;50% 时续租租约到期未续 → 地址回收
作用域选项003 路由器(网关)、006 DNS 服务器客户端拿不到网关 → 选项没配

跨网段分配 → 部署 DHCP 中继代理(把广播转单播到 DHCP 服务器)。 回顾第 9 课 DORA 四步,配置题常配抓包截图问步骤序号。

三、DNS 服务器

配置项含义
正向查找区域域名 → IP(建 A 记录、CNAME 别名、MX 邮件)
反向查找区域IP → 域名(PTR 记录)
根提示 / 转发器本地查不到时问谁:根提示走根;转发器转给上级 DNS
主/辅助区域辅助区域从主服务器区域传送复制(用 TCP 53)

验证:nslookup www.example.com 返回地址即成功。客户端"首选/备用 DNS"填的就是这台服务器地址。

四、WWW(IIS)与 FTP 服务器

服务关键配置考点
WWW(IIS)网站物理路径、绑定(IP:端口:主机名)、默认文档(index.html)、 SSL 证书(443)同一台机多网站:改端口或加主机名;访问 https 要装证书
FTP(IIS)主目录、读写权限、用户隔离、端口 21匿名 vs 授权登录;主动 vs 被动模式(防火墙后常用被动)
Email(概念)SMTP 服务 + POP3/IMAP 服务 + 邮箱域端口与收发协议回顾第 9 课
⚠️ 常见误区

"服务器 IP 用 DHCP 自动获取很方便"——错!服务器必须静态 IP (或 DHCP 保留),否则地址一变全公司断服。
"DNS 建了区域就能反向解析"——反向解析要建反向查找区域并配 PTR 记录。
"FTP 端口 21 传数据"——21 是控制连接;主动模式数据连接用 20, 被动模式用服务器随机高位端口。

🔧 工程视角

家里路由器的"DHCP 地址池""静态 IP 绑定"就是本课功能家用化;公司里的 OA/网站服务器 就是 IIS/FTP。三级综合题的配置题给一张 Windows Server 配置界面截图问 "空缺处该填什么"——把上面的表格背熟,选项基本一眼可辨。

五、检验你的理解

本课小结

要点一句话版本

WWW绑定、默认文档、SSL;多站靠端口/主机名区分
