网络层进阶 ARP · ICMP · NAT · Routing · IPv6

🎯 本课目标

学完本课(约 18 分钟),你将能够:

① 讲清 ARP 的工作过程与跨网段寻址; ② 说出 ICMP 的作用与 ping/traceroute 原理; ③ 对比 RIP/OSPF/BGP(高频考点),理解 NAT 与 IPv6 基础。

一、ARP:IP 地址 → MAC 地址

ARP(Address Resolution Protocol): 同一网段内,已知对方 IP 求其 MAC——主机广播 ARP 请求("谁是 192.168.1.20?"), 目标主机单播 ARP 应答;结果存入 ARP 缓存表。

跨网段关键逻辑(必考):源主机发现目的 IP 与自己不在同一网段 (IP AND 掩码比较,第 6 课!)→ 不直接找对方,而是把帧发给默认网关(路由器接口)的 MAC; 每过一个路由器,帧的源/目的 MAC 都被替换,而 IP 头里的源/目的 IP 始终不变 ——"MAC 逐段变,IP 端到端不变"。

二、ICMP:网络层的"诊断协议"

ICMP(Internet Control Message Protocol)封装在 IP 中, 两类报文:ICMP 询问(回送请求/应答)与 ICMP 差错报告 (终点不可达、超时、参数问题、改变路由)。
ping = 回送请求/应答,测连通性与往返时延;traceroute/tracert = 利用 TTL 逐跳递增,让沿途每台路由器返回超时报文,从而画出路径。

三、路由:静态 vs 动态,三大协议对比

路由器查路由表转发:目的网络 → 下一跳。路由来源:直连、静态(手工配,小网可靠) 与动态(协议自动学习)。动态分内部网关协议 IGP(一个自治系统 AS 内) 与外部网关协议 EGP(AS 之间):

协议算法度量承载要点
RIP Routing Information Protocol距离向量跳数(≤15,16=不可达)UDP 520小网络;周期广播;坏消息传得慢(慢收敛)
OSPF Open Shortest Path First链路状态 + Dijkstra开销(带宽)IP(协议号 89)大中型网络;泛洪链路状态;收敛快;区域划分
BGP Border Gateway Protocol路径向量策略(多准则)TCP 179AS 之间(互联网骨干);求"可达+策略好"而非最快

四、NAT 与 IPv6

NAT(Network Address Translation):内网私有地址 ↔ 公网地址转换。 常用 NAPT(端口地址转换):路由器记录"(内网IP:端口)→(公网IP:端口)"映射表, 回程按表翻回——你家路由器就是 NAT 设备;这也让外网无法主动连入内网(顺带的安全效果,需端口映射开放)。

IPv6:128 位,冒号十六进制表示,零压缩规则(每组前导 0 省略; 连续全 0 组用 ::,只能出现一次),如 2001:0db8:0000:0000:0000:ff00:0042:8329 → 2001:db8::ff00:42:8329。地址无前导 0 可省。过渡技术:双协议栈、 隧道。IPv6 不用 NAT、地址即充足;首部更简、内置安全与自动配置。

⚠️ 常见误区

"ARP 是运输层协议"——ARP/ICMP 都属于网络层(TCP/IP 网际层), ping 用的是 ICMP 不是 TCP/UDP。
"RIP 用带宽当度量,OSPF 用跳数"——正好说反:RIP 数跳数,OSPF 看开销(带宽)。
":: 可以压缩多个位置的连续零组"——错,只能用一次。

🔧 工程视角

家里断网的第一排查看法全是本课:ping 网关(ARP/连通性)→ ping 8.8.8.8(公网路由) → ping 域名(DNS,第 9 课)。三级应用题的"路由器配置"(IP、静态路由)与"网络故障诊断" 也建立在这层。记住排障顺序:物理连通 → 网关 → 路由 → DNS。
