# 第 3 课 · 整数规划

> [!abstract] 本课目标
> **①** 一眼识别「变量必须取整数」的场景;**②** 解释为什么对 LP 解四舍五入是错的;**③** 会用 `scipy.optimize.milp` 求解整数/0-1 规划,并用 0-1 变量表达「选/不选」。

## 一、什么时候必须整数

> [!important] 核心定义
> **整数规划**(integer programming, IP):给 LP 加上「变量必须取整数」的要求;变量只取 0 或 1 时叫 **0-1 规划**(binary programming),是国赛 B 题的常客。

人数、设备台数、选址(建/不建)、开关(投/不投)——这些量取 17.5 没有意义。

## 二、四舍五入为什么是错的

回到第 2 课的例子:LP 最优在顶点 $(17.5,\;15)$。四舍五入到 $(18,15)$?——违反约束 $2x+y\le50$($2\times18+15=51$),**根本不可行**。而真正的整数最优是 **$(18,14)$,$z=146$**,比 LP 上界 147.5 损失 1.5。

> [!important] 两个教训
> ① 取整可能**不可行**;② 取整可能**次优**。整数最优必须用算法找,不能手工凑。

## 三、分支定界:一分钟的直觉

求解器的主力算法是**分支定界**(branch and bound):先解 **LP 松弛**(不管整数要求)得到一个**上界**;若解非整数(如 $x=17.5$),就分成两支:$x\le17$ 和 $x\ge18$,各再解 LP……同时用当前最好整数解**剪掉**不可能更优的分支。理解它,你就能回答评审的追问:「为什么这个解是全局最优?」

## 四、milp 与 0-1 变量(大 M 法)

```python
from scipy.optimize import milp, LinearConstraint, Bounds
# 例:5 个候选站选 3 个(0-1),最小化建设成本
c = [12, 8, 15, 9, 11]                    # 各站成本
A = [[1,1,1,1,1]]                          # 总数恰好 3 个
res = milp(c=c, constraints=[LinearConstraint(A, 3, 3)],
           integrality=[1,1,1,1,1],        # 1 表示该变量必须整数
           bounds=Bounds(0, 1))            # 0-1 变量
```

建模技巧「**大 M 法**」:想表达「只有选了站 $i$($y_i=1$)才允许在那里建容量 $x_i$」,写 $x_i \le M\,y_i$。逻辑约束(至少建两个、A 建则 B 不建)都能用 0-1 变量的线性组合写出来。

> [!warning] 常见误区
> ① **对 LP 解取整**——本课刚反例过:不可行或次优
> ② **0-1 变量当成 0~1 连续变量**——`integrality` 忘了设,求解器当 LP 处理
> ③ **变量越多越稳**——整数规划是 NP-hard,几百个整数变量加烂约束就可能算不动;先精简变量与约束

> [!info]- 🔗 与已有学科连接
> - 第 2 课的**顶点直觉**仍然成立,只是可行域从连续多边形变成离散格点——所以最优可能「够不到」顶点
> - 检验环节新增一招:把 LP 松弛解当作**上界基准**,整数解离上界越近,解的质量越好(论文里可以报告这个间隙 gap)
> - 建环:设备启停台数、管段「敷设/不敷设」、末端「开/关」都是整数与 0-1 决策

## 五、检索练习(先回忆,再展开)

> [!question]- Q1 对 LP 最优解四舍五入得到整数解,问题出在哪?
> ✅ 两个坑都存在:取整点可能落在可行域外(不可行),即使可行也未必是整数最优(次优)。

> [!question]- Q2 0-1 规划里变量 y 的取值是什么?
> ✅ 只能取 0 或 1——二元变量是整数变量的特例,用于表达选/不选、开/关。

> [!question]- Q3 milp 与 linprog 的关键区别是?
> ✅ milp 可通过 `integrality` 参数逐变量指定整数要求(mixed-integer LP)。

> [!question]- Q4 分支定界算法中,LP 松弛解的作用是?
> ✅ 提供界(最大化问题给上界、最小化给下界),配合分支与剪枝保证全局整数最优。
