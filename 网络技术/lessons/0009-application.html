🎯 本课目标

学完本课(约 18 分钟),你将能够:

① 讲清 DNS 的层次结构与递归/迭代查询; ② 默写 DHCP 四步租约过程(综合题考报文分析); ③ 说出 HTTP/电子邮件/FTP 的工作要点与端口。

一、C/S 与 P2P:两种工作模型

客户/服务器模型(Client/Server):服务集中提供,客户请求-响应 (WWW、FTP、Email、DNS)。P2P(peer-to-peer): 每个节点既是客户又是服务器,对等共享(BT 下载),扩展性强、管理难。判断依据:谁服务谁。

二、DNS:域名的"查号台"

DNS(Domain Name System,UDP 53):把域名解析成 IP 地址。 域名树:根 → 顶级域(.com/.cn)→ 权限域。本地 DNS 服务器帮主机问路,问法两种:
查询方式过程要点
递归查询"替我问到底,把结果给我"主机 → 本地 DNS 通常用递归
迭代查询"我给你下一个线索,你继续问"本地 DNS → 根/顶级/权限服务器通常用迭代

常见资源记录:A(域名→IPv4)、CNAME(别名)、MX(邮件交换)、 PTR(IP→域名,反向解析)。

三、DHCP:插上网线就有 IP(综合题必考)

DHCP(Dynamic Host Configuration Protocol,UDP, 服务器 67/客户 68):主机开机广播四步拿地址—— Discover(我要 IP!)→ Offer(给你这个)→ Request(我要这个)→ Ack(成交,附掩码/网关/DNS/租约期)。

考点:全程 UDP;前两步是广播(此时主机还没有 IP);租约到期可续租; 跨网段要用 DHCP 中继代理把广播转成单播;可配置保留地址(MAC 绑定)、 排除范围、选项(网关/DNS)。综合题常给抓包问"这是第几步/为什么用广播"。

四、WWW、电子邮件与 FTP

服务协议/端口要点
WWW WebHTTP 80 / HTTPS 443URL = 协议://主机:端口/路径;HTTP 请求(方法 GET/POST+头部)+ 响应(状态码 200/404/500); HTTP1.1 持续连接省时;无状态 → 用 Cookie 记住会话;HTTPS = HTTP+SSL/TLS 加密
电子邮件SMTP 25(发/推)/ POP3 110(收/拉)/ IMAP(在线管理)"SMTP 推、POP3 拉";附件扩展用 MIME;Outlook 是 UA(用户代理)
文件传输 FTP控制 21 / 数据 20(主动模式)控制与数据两个连接分离;登录或匿名 FTP
远程登录Telnet 23 / SSH 22Telnet 明文,SSH 加密(工程用 SSH)
⚠️ 常见误区

"DNS 用 TCP"——常规查询用 UDP 53(快);区域传送(主从同步)才用 TCP。
"DHCP 客户端与服务器通信用 TCP 保证可靠"——DHCP 全程 UDP。
"POP3 收信也用 SMTP"——SMTP 负责推送(发件人与服务器间、服务器间); 用户从服务器拉取用 POP3/IMAP。

🔧 工程视角

"网页打不开"的排障链(第 7 课 + 本课):能 ping IP 但域名打不开 → DNS 故障; IP 也 ping 不通 → 网关/路由问题。三级综合题"DHCP 报文分析""DNS 服务器配置" 就是把本课表格背熟+看清题面。第 11 课会亲手配置这些服务器。
