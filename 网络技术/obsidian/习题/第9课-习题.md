## 一、基础题(≥8)

> [!question]- 1.1 默写 DHCP 获取地址的四步报文顺序,并指出使用的传输层协议。
> **答案**:Discover → Offer → Request → Ack(DORA);全程 UDP(服务器 67、客户端 68)。

> [!question]- 1.2 DHCP 前两步为什么用广播?
> **答案**:客户端此时还没有 IP、也不知道服务器在哪,只能以 0.0.0.0 为源、255.255.255.255 为目的广播寻服务器。

> [!question]- 1.3 DNS 的递归查询与迭代查询有什么区别?各常用在哪一段?
> **答案**:递归=替我问到底、给最终答案(主机→本地 DNS);迭代=给线索、你自己继续问(本地 DNS→根/顶级/权限服务器)。

> [!question]- 1.4 写出 A、CNAME、MX、PTR 四种记录的含义。
> **答案**:A 域名→IPv4;CNAME 别名指向规范域名;MX 邮件交换服务器;PTR 反向解析(IP→域名)。

> [!question]- 1.5 URL 的组成?HTTP 常用方法与两个常见状态码?
> **答案**:协议://主机:端口/路径;方法 GET(取)/POST(交);状态码 200 成功、404 未找到(再加 500 服务器错)。

> [!question]- 1.6 SMTP 与 POP3/IMAP 的分工?
> **答案**:SMTP(25)负责推信——用户代理→发送服务器、服务器间转发;POP3(110)/IMAP 负责用户从服务器拉取/在线管理。

> [!question]- 1.7 FTP 为什么需要两个连接?端口各是什么?
> **答案**:控制连接(21,传命令,全程保持)与数据连接(主动模式 20,按需建立)分离,命令与数据互不干扰。

> [!question]- 1.8 HTTP 是无状态协议,网站如何"记住"登录用户?
> **答案**:用 Cookie(服务器下发、浏览器携带)标识会话;配合服务器端 Session;HTTPS 在其下加密保证安全。

## 二、工程应用题(≥2)

> [!question]- 2.1 用户报告"QQ 能用但网页打不开"。QQ 走自家协议直连服务器,网页要域名解析。请给出诊断思路。
> **答案**:网络连通但域名解析失败 → DNS 问题。验证:ping 一个公网 IP(通)→ `nslookup` 域名(失败);处理:检查客户端 DNS 配置/更换备用 DNS(如 114.114.114.114)/排查 DNS 服务。

> [!question]- 2.2 公司部署邮件系统:员工用 Outlook 收发信。写出需要配置的服务器角色与协议端口,并说明"给 example.com 发信"时本方服务器如何找到对方。
> **答案**:需 SMTP 服务(25,发/中继)+ POP3(110)/IMAP(收)服务;客户端 SMTP/POP3 指向本方服务器。发往 example.com:本方 SMTP 通过 DNS 查询该域的 **MX 记录**找到其邮件服务器,再 SMTP 推送过去。

## 三、开放思考题(1)

> [!question]- 3.1 你家路由器的"DHCP 地址池"与第 11 课要学的"DHCP 服务器"是同一个东西吗?从功能裁剪的角度谈谈家用设备与服务器版的差异。
> **答案**:开放思考。要点:协议同一(DORA),实现是裁剪版——家用路由只提供地址池/租约/简单保留,作用域单一;服务器版支持多作用域、排除、选项定制、中继、容错。理解"协议标准 vs 产品实现"的差异,是考题里"该功能由谁提供"类判断的钥匙。

## 四、概念陷阱选择题(识别干扰项)

> [!question]- 4.1 关于 DNS,正确的是?
> **A.** 常规查询用 TCP 53 　**B.** 常规查询用 UDP 53,区域传送用 TCP 　**C.** 必须递归查询
> > [!success]- 答案
> > **B**。查询报文小、求快用 UDP;主从区域传送要可靠才用 TCP;主机到本地 DNS 常递归,服务器间常迭代。

> [!question]- 4.2 用户从邮件服务器**读取**邮件用的是?
> **A.** SMTP 　**B.** POP3 或 IMAP 　**C.** SNMP
> > [!success]- 答案
> > **B**。SMTP 管"推"(发送与服务器间),POP3/IMAP 管"拉/读";SNMP 是网络管理协议,纯干扰项。

> [!question]- 4.3 DHCP 客户端与服务器之间使用的传输层协议是?
> **A.** TCP 　**B.** UDP 　**C.** ICMP
> > [!success]- 答案
> > **B**。全程 UDP;广播阶段连 IP 都没有,更谈不上 TCP 连接。
