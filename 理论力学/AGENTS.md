# AGENTS.md — 理论力学工作区指令

本目录是「理论力学」学科工作区(库根 `D:/学习`)。在此目录工作的会话必须遵守本文件。

## 会话开始(必做,按顺序)

1. 读 `MISSION.md` — 使命:力学体系地基,与流体力学并行;微积分✅、矢量✅、普物力学✅,直接讲方法论。
2. 读 `RESOURCES.md` — 可信来源(哈工大《理论力学》为主教材,MIT OCW 8.01 对照)。
3. 读 `NOTES.md` — 工作流细则、验收标准、已出课程与当前进度。
4. 跨学科流程以库根 `D:/学习/课程工作流.md` 为唯一权威;本学科采用**批量化工作流**
   (全部课程已产出,用户自学 + 提问落 Q&A + 错题追加变式)。

## 硬性约定(必守)

- 课程正文在 `lessons/NNNN-<slug>.html`(共 12 课,按静力学→运动学→动力学组织);
  手册重建:`python ../build_coursebook.py .`(脚本在库根,跨学科共用,改动需谨慎)。
- 每课有"衔接框":点出与流体力学/CFD 的对应(受力分析↔流体微元受力、动量定理↔动量方程等)。
- 无外部考试,验收走能力标准(M1~M4,见 NOTES.md 考试锚点)。
- Q&A 自动落盘:概念性追问/主题讲透后,在 `obsidian/问答/` 建笔记并更新 `问答库.base`。
- 习题 Obsidian-only:只在 `obsidian/习题/第N课-习题.md`,正文只放 📝 入口链接;
  用户做错/追问后按 `## 错题与变式` 追加变式题。
- 手册风格保持学术纸感(assets/style.css),不要改成深色或花哨风格。

## 已安装技能(用户级)

`obsidian-markdown`、`json-canvas`、`obsidian-bases`、`obsidian-cli`、`defuddle`、
`teach`、`anysearch`、`grill-me` —— 写 `.md`/`.canvas`/`.base` 或操作 Obsidian 库、联网检索时优先使用。
