网络安全与管理 Security & Management

🎯 本课目标

学完本课(约 20 分钟),你将能够:

① 说出安全五目标与加密/签名体系; ② 讲清防火墙/DMZ/IDS 的部署逻辑,会读写标准与扩展 ACL; ③ 记住 SNMP 组件与无线网络安全演进(选择题高频)。

一、安全五目标(必背)

目标英文一句话
机密性Confidentiality只有该看的人看得懂(加密)
完整性Integrity没被篡改(摘要/签名)
可用性Availability该用时用得了(抗 DoS/冗余)
真实性(可认证)Authenticity身份是真的(认证/证书)
可控性Controllability行为可管可控(审计)

加密体系:对称加密(DES/3DES/AES——快,密钥分发难,双方同一把钥匙) vs 非对称加密(RSA——公钥加密私钥解,慢,解决密钥分发)。 实战组合:非对称交换对称密钥,再用对称加密传数据(HTTPS 就这样)。 数字签名 = 发方用自己的私钥对摘要加密(认证+完整性+不可否认); 数字证书由 CA(认证中心)签发,证明"公钥确实是他的"。 常见攻击:DoS/DDoS(耗尽资源)、钓鱼、中间人、ARP 欺骗、SQL 注入。

二、防火墙、DMZ 与 IDS

防火墙(firewall):位于内外网之间的访问控制点。 三类:包过滤(网络层,查 IP/端口,快但粗)、 状态检测(跟踪连接状态)、应用网关/代理(应用层,细但慢)。

DMZ(demilitarized zone 非军事区):外网↔DMZ↔内网三区结构, Web/FTP/Mail 等对外服务器放 DMZ——被攻破也不至于直捣内网。 内网 → DMZ 允许、DMZ → 内网默认拒绝。
IDS 入侵检测系统:监听旁路报警(不拦截);IPS 则串路在线拦截。

三、ACL:路由器上的门禁(配置题常客)

类型编号匹配依据要点
标准 ACL standard1~99仅源 IP放靠近目的的接口(免得误杀路上流量)
扩展 ACL extended100~199源/目的 IP + 协议 + 端口放靠近源的接口(尽早拦截)

规则:自上而下逐条匹配,命中即停;末尾隐含 deny all(至少要有一条 permit); 通配符掩码(wildcard,0=严格匹配,1=任意,如 0.0.0.255 匹配一个 C 段);方向分 in/out。

四、SNMP 与无线安全

SNMP(Simple Network Management Protocol,UDP 161/162): 管理站(NMS)↔ 设备上的代理(Agent),代理维护 MIB(管理信息库); 操作:Get(读)/Set(写)/Trap(代理主动报警,发往 162)。版本 v3 加了认证加密。

无线网络:IEEE 802.11 家族(11a/b/g/n/ac/ax,2.4G 与 5G 频段;11b/g/ax 在 2.4G); AP 广播 SSID;安全演进(必背顺序,越往后越安全): WEP(已破解,禁用)→ WPA(TKIP,过渡)→ WPA2(AES/CCMP,当前主流)→ WPA3(最新)。 家庭路由器选 WPA2/WPA3-Personal(PSK 预共享密钥),企业用 802.1X 认证。

⚠️ 常见误区

"数字签名用接收方的公钥加密"——签名用发送方的私钥; 用接收方公钥加密的是保密(机密性),两者目的不同。
"标准 ACL 可以匹配端口号"——不能,标准 ACL 只看源 IP;要看端口用扩展 ACL。
"WPA2 已经被破解所以不如 WEP 稳"——方向反了,WEP 早已淘汰;KRACK 类攻击已有补丁, WPA2+WPA3 混合模式是当前家用最佳选择。
