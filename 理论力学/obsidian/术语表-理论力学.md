# 理论力学术语表

本课程的统一语言。每一课都遵守这里的译名与符号约定。

> [!tip] 用法
> 每个术语都是独立小节,方便用 `[[术语表-理论力学#术语]]` 精确链接。

## 静力学公理(五)

二力平衡、加减平衡力系、平行四边形、作用反作用、刚化原理。详见 [[第1课-静力学公理与受力分析]]。

## 约束 / 约束力

限制运动的物体条件 / 其反作用:限制哪个方向,约束力就顶在哪个方向。

## 二力杆

两端受力、自重不计、平衡的构件:两端力沿连线等值反向。

## 受力图

隔离体 + 主动力 + 约束力的规范图;四步:隔离→主动→约束→检查。

## 固定铰 / 活动铰 / 固定端

铰 2 分量 / 滚支 1 法向力 / 固定端 3 量(两力一偶)。详见 [[第2课-平面汇交力系与力偶]]。

## 汇交力系

各力作用线汇交一点的力系;解析法:ΣFx=0、ΣFy=0。

## 力对点之矩 / 合力矩定理

Mo=±Fd(逆时针正);合力矩=分力矩代数和。

## 力偶 couple

等值反向不共线两力:合力为零只转不推;面内移转不变;只与力偶平衡。

## 力线平移定理

力平移需附加力偶 M=Mo(F);固定端模型的来源。

## 主矢 / 主矩

R′=ΣF(与简化中心无关);Mo=ΣMo(F)(有关)。详见 [[第3课-平面任意力系]]。

## 平衡方程(三种形式)

基本式/二矩式/三矩式,各 3 个独立方程;矩心选未知力交点。

## 静定 / 静不定

未知量≤方程数可解;超出需变形条件(材料力学)。

## 物系平衡

先整体(内力不出场)后拆开(反作用成对)。

## 库仑摩擦定律

0≤Fs≤fs·FN;等号仅在临界/滑动。详见 [[第4课-摩擦]]。

## 摩擦角 / 自锁

tanφs=fs;主动力线入摩擦锥则多大力都不滑;斜面 α≤φs。

## 滚动摩阻

Mf≤δ·FN(δ 长度量纲)——轮子的力学本质。

## 自然法 / 切向与法向加速度

轨迹已知用弧坐标;aτ=dv/dt 管大小、an=v²/ρ 管方向。详见 [[第5课-点的运动学]]。

## 刚体 rigid body

任意两点距离恒不变;平移与定轴转动为基本运动。详见 [[第6课-刚体的基本运动]]。

## 定轴转动 / 角速度

一个 φ(t) 定全场;ω=dφ/dt、α=dω/dt;v=ωr、aτ=αr、an=ω²r。

## 传动比

i=ω₁/ω₂=r₂/r₁=z₂/z₁(不打滑)。

## 定系 / 动系

地面参考系 / 架在承载滑动构件上的参考系。详见 [[第7课-点的合成运动]]。

## 绝对 / 相对 / 牵连速度

va=真实;vr=相对动系;ve=动系上重合点的速度;va=ve+vr。

## 科氏加速度 Coriolis

aC=2ω×vr(vr 顺 ω 转 90°);动系平移时为零;地转偏向力与旋转 CFD 的来源。

## 平面运动 / 基点法

随基点平移+绕基点转动;vB=vA+vBA,ω 与基点无关。详见 [[第8课-刚体的平面运动]]。

## 速度投影定理

两点速度沿连线投影相等(刚体不变形);给不出 ω。

## 速度瞬心 / 瞬时平移

该瞬时速度为零的点(纯滚动=接触点);两速度平行相等 → 瞬心无穷远、ω=0。

## 质点动力学两类问题

知运动求力(求导);知力求运动(解 ODE)。详见 [[第9课-质点动力学与动量定理]]。

## 动量 / 动量定理

P=Mvc;dP/dt=ΣF外(内力不出场)。

## 质心运动定理 / 动量守恒

MaC=ΣF外;某方向外力为零 → 该方向动量守恒(人船问题)。

## 动量矩 / 转动惯量

Lo=r×mv;定轴刚体 Lz=Jz·ω,Jz=Σmr²。详见 [[第10课-动量矩定理]]。

## 动量矩定理 / 定轴转动微分方程

dLo/dt=ΣMo(固定点/质心);Jz·α=ΣMz;外力矩零 → 守恒。

## 平行轴定理 / 回转半径

Jz=JC+Md²(必须过质心);J=Mρ²。

## 功 / 动能

mgh、½k(x₁²−x₂²)、Mφ、摩擦 −Fs;½Mv²、½Jω²、½Mvc²+½JCω²(柯尼希)。详见 [[第11课-动能定理]]。

## 动能定理 / 功率方程

T₂−T₁=ΣW(标量方程);dT/dt=ΣP。

## 理想约束

约束力不做功:光滑面/铰/不可伸长绳/纯滚动接触点。

## 惯性力 / 动静法

FI=−ma(虚构力);加上惯性力把动力学变平衡题,求动反力。详见 [[第12课-达朗贝尔原理与虚位移]]。

## 虚位移 / 虚功原理

约束允许的假想位移;理想约束下平衡 ⟺ ΣδW主动=0;通向拉格朗日力学。

## 惯性参考系 / 非惯性系

无加速度参考系(牛顿定律成立)/ 加速或转动的参考系(需补惯性力)。详见 [[第13课-非惯性系中的质点动力学]]。

## 牵连惯性力 / 科氏惯性力

F_Ie=−ma_e;F_IC=−2mω×v_r。旋转 CFD 动量方程附加项的力学来源。

## 相对平衡

v_r=0、a_r=0:ΣF+F_Ie=0;旋转液面 z=ω²r²/2g(抛物面)。

## 碰撞冲量 / 恢复系数

碰撞只记冲量、位置冻结;e=|分离|/|接近|(法向),e=1 弹性、0 塑性。详见 [[第14课-碰撞]]。

## 撞击中心

h=Jz/(ma):定轴刚体受撞此处轴承零碰撞反力(甜区)。

## 平面运动微分方程(刚体)

maCx=ΣFx、maCy=ΣFy、JC·α=ΣMC;纯滚 aC=g·sinθ/(1+J/mR²)。详见 [[第15课-刚体平面运动动力学]]。

## 密歇尔斯基方程 / 反冲推力

M·dv/dt=F外+u相对·(dM/dt);P=u·|dM/dt|。详见 [[第16课-变质量动力学]]。

## 齐奥尔科夫斯基火箭方程

Δv=u·ln(M₀/M末);对数律 → 多级火箭。

## 自由度 / 广义坐标 / 广义力

独立参数个数 / 描述它的变量(让约束自动满足)/ δW=ΣQj·δqj 的系数。详见 [[第17课-分析力学I-广义坐标与拉格朗日方程]]。

## 拉格朗日方程(第二类)

d/dt(∂L/∂q̇j)−∂L/∂qj=Qj,L=T−V;理想约束力自动消去。

## 循环坐标 / 广义动量守恒 / 能量积分

L 不含 q → pj 守恒;L 不显含 t → T+V 守恒(对称性给守恒律)。详见 [[第18课-分析力学II-守恒律与哈密顿视角]]。

## 哈密顿函数 / 正则方程 / 相空间

H(q,p)=Σp·q̇−L;q̇=∂H/∂p、ṗ=−∂H/∂q;(q,p) 状态空间,现代物理的通用语言。
