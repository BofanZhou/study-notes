# 第 9 课 · 应用层协议

> [!important] DHCP 四步(综合题报文分析)
> **D**iscover → **O**ffer → **R**equest → **A**ck,全程 **UDP**;
> 前两步广播;租约/保留/排除/中继代理。

## DNS

- 层次:根 → 顶级 → 权限;UDP 53(区域传送用 TCP)
- 主机→本地 DNS 用**递归**;本地→根/顶级/权限用**迭代**
- 记录:A(域名→IP)、CNAME(别名)、MX(邮件)、PTR(反向)

## 协议端口速记

HTTP 80 / HTTPS 443 · SMTP 25(推)· POP3 110(拉)· IMAP(在线)· FTP 控 21 数 20 · Telnet 23 / SSH 22

> [!warning] 陷阱
> DNS 常规查询用 UDP;SMTP 只管"推",收信是 POP3/IMAP;
> HTTP 无状态靠 Cookie 补;HTTPS = HTTP+SSL/TLS。
