术语表 Glossary

每个术语给一句话本质解释 + 英文对照。课程中首次出现的术语会追加到这里。

术语English一句话解释
工程经济学engineering economics把技术方案全寿命现金流量换到同一时点,用经济判据评价与比选。
现金流入/流出cash inflow / outflow (CI/CO)进入/离开方案的钱;净现金流量 NCF = CI − CO。
现金流量图cash flow diagram横轴时间、上入下出;大小、方向、时点三要素缺一不可。
资金时间价值time value of money来源 = 机会成本 + 通胀 + 风险;市场表现是利息。
单利simple interestF = P(1+n·i),利息不再生息;工程经济不用。
复利compound interestF = P(1+i)^n,利滚利;工程经济一律复利。
72 法则rule of 72复利翻倍年数 ≈ 72/i(%)。
等值equivalence考虑时间价值后「价值相等」;不同时点的钱先换算再比较。
现值/终值/年金present / future value, annuity (P/F/A)0 点一次性 / n 点一次性 / 每期期末等额序列。
一次支付终值系数(F/P, i, n)(1+i)^n;已知 P 求 F。
一次支付现值系数(P/F, i, n)(1+i)^−n;已知 F 求 P,「折现」动作本体。
等额分付终值系数(F/A, i, n)[(1+i)^n−1]/i;几何级数求和,六系数之源。
偿债基金系数(A/F, i, n)i/[(1+i)^n−1];要攒到 F,每年存多少。
等额分付现值系数(P/A, i, n)[(1+i)^n−1]/[i(1+i)^n];A 序列折现,节能项目必背。
资本回收系数(A/P, i, n)i(1+i)^n/[(1+i)^n−1];已知 P 求 A,等额本息;(A/P)=(A/F)+i。
名义利率nominal rate (r)年挂牌利率;除以年计息次数 m 得周期利率。
实际利率effective rate (i_a)(1+r/m)^m − 1;计息越频繁越高,连续计息上界 e^r − 1。
基准收益率benchmark rate (i_c)投资回报及格线;折现用的官方门槛,不是银行利率。
净现值net present value (NPV)净现金流按 i_c 折现求和;NPV ≥ 0 = 达标还有超额。
内部收益率internal rate of return (IRR)NPV=0 的折现率;非常规现金流可能多解。
静态/动态投资回收期static / dynamic payback period累计净现金流转正年数;动态折现后恒 ≥ 静态。
净年值net annual value (NAV)NPV × (A/P, i_c, n);不同寿命比选的通行证。
互斥方案mutually exclusive alternatives只能选一;同口径比 NPV/年值取大。
增量分析incremental (Δ) analysis「贵−便宜」当虚拟项目;ΔIRR ≥ i_c 选投资大的。
Fisher 交点Fisher intersection两方案 NPV–i 曲线交点 = ΔIRR;i_c 两侧结论反转。
费用现值/费用年值present cost (PC) / annual cost (AC)只有费用流时比谁花钱少;PC 取小,寿命不同用 AC。
盈亏平衡点break-even point (BEP)Q* = F/(p−v);BEP 越低越抗风险。
单位边际贡献unit contribution marginp − v;每件产品摊固定成本的能力。
敏感性分析sensitivity analysis单因素扰动看 NPV 响应;产出敏感度排序与临界点。
敏感度系数sensitivity coefficient (S)S = (ΔNPV/NPV)/(ΔX/X);直线斜率。
临界点switching valueNPV=0 的因素变动幅度;翻车安全距离。
期望值法expected value methodE(NPV) = Σ P_i·NPV_i;给概率性风险称重。
折旧depreciation价值逐年转移;非现金流,经税盾影响税后现金。
直线法straight-line methodD = (K−L)/n,均匀折旧。
双倍余额递减法double declining balance(2/n)×期初净值;末两年改直线扣残值。
年数总和法sum-of-years-digits (SYD)按剩余年数占比递减的加速折旧。
税盾tax shield折旧 × 税率 = 少交的税 = 现金收益。
有形/无形磨损physical wear / obsolescence使用锈蚀损耗 / 技术进步贬值。
经济寿命economic life年均总成本 U 形最低点;n* ≈ √(2(K−V)/λ)。
低劣化数值法degradation methodAC(n) = (K−V_n)/n + C₁ + (n−1)λ/2。
沉没成本sunk cost覆水难收,不参与更新决策;旧设备按现市价计。
寿命周期成本life-cycle cost (LCC)设置费 + 维持费,折现后比总账;暖通比选的正确尺子。
价值工程value engineering (VE)以最低 LCC 可靠实现必要功能;V = F/C。
功能系数/成本系数function / cost index (FI/CI)功能得分占比 / 成本占比;V = FI/CI < 1 是改进对象。
