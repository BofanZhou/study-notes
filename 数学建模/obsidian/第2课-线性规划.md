# 第 2 课 · 线性规划

> [!abstract] 本课目标
> **①** 把「生产/配比/分配」类问题翻译成 LP 三要素(决策变量、目标函数、约束);**②** 用图解法理解「最优必在顶点」;**③** 用 `scipy.optimize.linprog` 一步求解。

## 一、三要素与标准形式

> [!important] 核心定义
> **线性规划**(linear programming):目标与约束都是决策变量的**线性函数**,在有限资源下求最优分配——大量赛题的本质都是「资源有限,如何分配,使收益最大或成本最小」。它是国赛第一模型族。

三要素:**决策变量**(decision variables,先写清变量与单位)→ **目标函数**(objective,如 max $z=5x+4y$)→ **约束条件**(constraints,资源/工时/需求一条条列)。评审第一条看的就是这一步是否严谨。

$$\max\; c^Tx \qquad \text{s.t.}\quad Ax\le b,\; x\ge 0$$

## 二、图解法:最优必在顶点

每条约束画成半平面,交集是一个**凸多边形** = **可行域**(feasible region)。目标函数的等值线 $z=5x+4y$ 是一族平行直线,$z$ 越大直线越远离原点;等值线即将离开可行域的那一刻,接触的必然是一个**顶点**。

> [!important] 顶点定理
> LP 的最优必可在可行域顶点取到——顶点由约束交出,这也是单纯形法的全部直觉。

## 三、编程求解:linprog

```python
from scipy.optimize import linprog
# linprog 默认求最小值,故目标取负:max 5x+4y → min -5x-4y
c = [-5, -4]
A = [[2, 1], [1, 2], [0, 1]]     # 左端系数
b = [50, 60, 15]                 # 右端上限
res = linprog(c, A_ub=A, b_ub=b, bounds=[(0, None), (0, None)])
print(res.x, -res.fun)           # x=[17.5, 15.], z=147.5
```

例题:max $z=5x+4y$,s.t. $2x+y\le50$、$x+2y\le60$、$y\le15$、$x,y\ge0$ → 最优在顶点 **$(17.5,\;15)$**,$z=147.5$。

记住两个对应关系:**≤ 约束 → `A_ub`/`b_ub`**;**min → max 取负号**;等式约束用 `A_eq`/`b_eq`。

> [!warning] 常见误区
> ① **约束方向写反**——「至少」「不超过」要逐句核对,这是 LP 代码第一大 bug 源
> ② **忘了 linprog 是 min**——忘记取负号会得到「最优在原点」的可疑结果
> ③ **把 LP 解当最终答案**——产量可以切割到 17.5 台吗?变量该取整数时,请进第 3 课

> [!info]- 🔗 与已有学科连接
> - 线性代数:约束组 $Ax\le b$ 就是矩阵语言的落地;顶点由约束交出,约束变一变顶点就搬家——这正是论文**灵敏度分析**的入口(影子价格 shadow price,全真模拟前补讲)
> - 建环:冷水机组开几台、新风量怎么分、夜间预冷时段怎么排——「有限资源怎么分配」翻译过来就是 LP(见本课习题 2.1/2.2)

## 四、检索练习(先回忆,再展开)

> [!question]- Q1 用 linprog 求 max z=5x+4y,目标向量怎么写?
> ✅ 取 $c=[-5,-4]$——linprog 只会 min,$\min -5x-4y$ 等价于 $\max 5x+4y$。

> [!question]- Q2 「最优必在顶点」成立的前提是什么?
> ✅ 目标与约束都是线性:线性等值线在离开凸多边形可行域前,最后接触的必然是顶点。

> [!question]- Q3 「甲原料用量不超过 50 千克」在标准形式中属于什么?
> ✅ 一条 ≤ 约束,直接进 `A_ub`/`b_ub`;「至少/不低于」才是 ≥(进 A_ub 前要取负号)。

> [!question]- Q4 把「选择建或不建某设施」直接放进 LP,错在哪?
> ✅ 该决策本质是 0-1(整数)变量,LP 的连续解没有意义——这正是第 3 课的主题。
