摩擦 Friction

🎯 本课目标

学完本课(约 15 分钟),你将能够:

① 用库仑摩擦定律处理"考虑摩擦的平衡"; ② 用摩擦角与自锁条件秒判"滑不滑"; ③ 了解滚动摩阻的模型。

一、滑动摩擦:一个"有上限的约束力"

接触面粗糙时,切向出现静摩擦力 Fs。它不是定值,而是被动力: 大小随主动力变化,平衡时 0 ≤ Fs ≤ Fmax,上限由库仑摩擦定律给出:

Fmax = fs · FN —— 与接触面积无关,只看法向压力与静摩擦系数 fs。 一旦滑动,动摩擦 Fd = fd·FN(fd 略小于 fs,近似认为相等)。

考虑摩擦的平衡问题标准流程:① 先按无摩擦列平衡方程;② 补充临界条件 Fs = fsFN;③ 解出临界值 → 答案往往是一个范围 (Fmin ≤ F ≤ Fmax),因为摩擦可以"双向顶住"。

二、摩擦角与自锁:几何法的威力

摩擦角 φs:临界状态下,法向反力 FN 与最大静摩擦力 Fmax 的全约束反力与法线的夹角,tan φs = fs。

把"法向 + 切向"两个约束力合起来看:全反力只能落在以法线为轴、半角 φs 的锥面内 (摩擦锥)。于是得到暴力而优雅的判据——自锁条件:

判据内容
自锁主动力合力的作用线落在摩擦锥之内 → 无论力多大都滑不动(驱动再猛,摩擦同步长大)
经典例斜面上物块不滑的条件:斜面倾角 α ≤ φs(螺纹、千斤顶、楔块设计的理论基础)

三、滚动摩阻:为什么轮子省力

滚动时接触面并非理想点:法向反力前移一段距离 δ,形成滚动摩阻力偶 Mf ≤ δ·FN (δ 为滚阻系数,量纲是长度)。δ 通常极小 → 推滚比推滑省力几个数量级—— 轴承、轮子的力学本质。

⚠️ 常见误区

"摩擦力总阻碍运动"——摩擦力阻碍的是相对滑动趋势; 人走路、车轮驱动、皮带传动,摩擦力都是动力。
"F = f·FN 永远成立"——只有达到最大(临界或滑动)时才取等号; 静止时 Fs 由平衡方程求出,通常小于上限。顺序:先用平衡求 Fs,再验证 ≤ fsFN。
"接触面越大摩擦越大"——库仑定律里根本没有面积项(近似模型内)。

🌊 衔接:流体力学中它在哪

流体没有静摩擦力——这正是流体力学第 1 课"流体不能抵抗剪切"的另一面: 再小的切向力都会让流体持续变形。固体靠摩擦"站得住",流体靠压强"传得开"。 两种介质的边界条件也由此分野:固体壁面上流体黏附(no-slip),靠的是黏性而非库仑摩擦。
