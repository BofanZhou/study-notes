## 🗺️ 阶段规划

### P0 · 地基(✅ 已完成)

- [x] 第 1 课 · 什么是计算机网络(定义三要素 / LAN-MAN-WAN / 五种拓扑)

### P1 · 概念骨架(单选 40 分的主战场)

- [x] 第 2 课 · 数据交换方式:电路交换 / 报文交换 / 分组交换(选择题常客)
- [x] 第 3 课 · 网络体系结构:OSI 七层 vs TCP/IP,各层功能与所属设备(**全考试核心**)
- [x] 第 4 课 · 物理层:传输介质(双绞线/光纤)、编码、带宽与信道容量计算
- [x] 第 5 课 · 数据链路层与局域网:MAC、以太网、交换机原理、VLAN
- [x] 第 6 课 · 网络层与 IP 地址(①):分类地址、子网划分、CIDR —— **综合题第一考点,课量加倍**
- [x] 第 7 课 · 网络层(②):ARP/ICMP、NAT、IPv6 基础
- [x] 第 8 课 · 路由:静态/动态路由、RIP/OSPF/BGP 概念、路由器基础配置
- [x] 第 9 课 · 传输层:TCP/UDP、三次握手、流量与拥塞控制

**验收 M1**:不看书画出 OSI/TCP-IP 层次对照表;子网划分笔算 5 题全对;单选模拟 ≥ 32/40。

### P2 · 考试专属模块(官方教材特有的"工程内容")

- [x] 第 10 课 · 中小型网络系统总体规划与设计(需求调研、设备选型、结构化布线、IP 分配方案)——综合题"规划"题源
- [x] 第 11 课 · 信息服务系统:DHCP / WWW / DNS / FTP 服务器安装与配置——综合题考 DHCP 报文分析与服务器配置
- [x] 第 12 课 · 网络安全与管理:防火墙、加密与认证、病毒、ACL、SNMP;无线网络基础

**验收 M2**:能默写交换机/路由器基本配置命令清单;官方样题综合题部分 ≥ 30/40。

### P3 · 真题冲刺(题库 + 样题)

- [ ] 章节刷题:按考纲板块刷单选(题库选定见 [[RESOURCES|题库候选]],先试用再定一本)
- [ ] 综合题专项:地址规划填表(每日 2 题)+ 配置命令默写(每日 1 组)
- [ ] 应用题专项:交换机 / 路由器配置真题逐题吃透
- [ ] 套卷模拟:官方样题 + 近年真题,限时 120 分钟

**验收 M3**:最近 2 套限时真题 ≥ 80 分且单选 ≥ 32/40。

### P4 · 考前一周

- [ ] 错题本全部过一遍(`## 错题与变式` 从第 1 课就开始积累)
- [ ] 配置命令、端口号、协议号默写清单 ×3
- [ ] 考点速览表(每课"本课小结"合并打印)
- [ ] 最后 2 套全真模拟,调整作息到考试时段
