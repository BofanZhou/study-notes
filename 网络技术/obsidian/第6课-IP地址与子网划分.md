# 第 6 课 · IP 地址与子网划分(★综合题核心)

> [!important] 三件套算法(必会)
> 网络地址 = IP **AND** 掩码;广播地址 = 下一网络地址 − 1;可用主机 = **2ʰ − 2**。
> 块大小 = 256 − 掩码末段;IP 落在哪个块,网络地址就是块起点。

## 分类与特殊地址

| 类 | 首位 | 默认掩码 | 首字节范围 |
| --- | --- | --- | --- |
| A | 0 | /8 | 1~126 |
| B | 10 | /16 | 128~191 |
| C | 110 | /24 | 192~223 |
| D/E | 1110/1111 | — | 多播 / 保留 |

- 环回 **127.x.x.x**;私有段:**10/8、172.16~172.31、192.168/16**
- 主机位全 0 = 网络地址,全 1 = 广播地址,均不可分配

## 划分口诀

借 n 位子网:2ⁿ ≥ 子网数;主机 h 位:2ʰ−2 ≥ 主机数。
例:60 台 → h=6 → **/26**(掩码 .192),可用 62 台。

> [!warning] 陷阱
> /24 可用 254 不是 256;子网借位越多,每子网主机越少;
> 块大小法:256 − 掩码末段(如 .192 → 块 64),IP 落进哪个块,网络地址就是该块起点。
