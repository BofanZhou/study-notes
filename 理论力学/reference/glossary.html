理论力学术语表 Glossary

本课程的统一语言。每一课都遵守这里的译名与符号约定; 遇到不确定的术语,先回到这里查。

静力学(第 1~4 课)

静力学五公理 axioms
二力平衡、加减平衡力系、平行四边形、作用反作用、刚化原理——静力学的"许可证"。
约束 / 约束力 constraint
限制哪个方向的位移,约束力就顶在哪个方向;柔索拉、光滑面法向、固定铰两分量、活动铰一力、二力杆沿杆、固定端两力一偶。
二力杆 two-force member
两端受力、自重不计、平衡 → 两端力沿连线等值反向。
受力图 free-body diagram
隔离体 → 主动力 → 逐处补约束力 → 检查;力学的"识字课"。
汇交力系解析法
ΣFx=0、ΣFy=0;投影带符号,合力投影定理。
力偶 couple
等值反向不共线:合力为零只转不推;面内移转不变;只与力偶平衡。
力线平移定理
力平移到新点必附加力偶 M=Mo(F);固定端约束(两力一偶)的来源。
主矢 / 主矩
R′=ΣF 与简化中心无关;Mo=ΣMo(F) 与中心有关(差 R′×d)。
平衡方程三形式
两投影一矩 / 二矩式(连线不⊥轴)/ 三矩式(三点不共线),各 3 个独立方程。
静定 / 静不定
未知量≤方程数可解;超出需变形协调条件(材料力学接手)。
库仑摩擦定律
0≤Fs≤fs·FN;等号仅在临界或滑动;摩擦是被动力。
摩擦角 / 自锁 self-locking
tanφs=fs;主动力线入摩擦锥 → 多大力都不滑;斜面 α≤φs。
滚动摩阻
Mf≤δ·FN,δ 有长度量纲且极小——轮子省力的本质。

运动学(第 5~8 课)

三种描述法
矢量法(定义)、直角坐标法(分量求导)、自然法(轨迹已知,弧坐标)。
切向 / 法向加速度
aτ=dv/dt 管速度大小;an=v²/ρ 管方向(指向曲率中心)。
刚体 rigid body
任意两点距离恒不变;平移与定轴转动为基本运动。
平移 translation
体内直线方向不变(轨迹可曲线);同一时刻各点 v、a 处处相同。
定轴转动
一个 φ(t) 定全场:ω=dφ/dt、α=dω/dt;v=ωr、aτ=αr、an=ω²r。
传动比 gear ratio
i=ω₁/ω₂=r₂/r₁=z₂/z₁(不打滑),多级连乘。
动系 / 牵连速度
动系架在承载滑动的构件上;ve=动系上与动点重合之点的速度(=ω×当前 r)。
速度合成定理
va=ve+vr(矢量三角形);vr 沿杆/槽。
科氏加速度 Coriolis
aC=2ω×vr(vr 顺 ω 转 90°);动系平移时为零;地转偏向力与旋转 CFD 附加项的来源。
平面运动 / 基点法
随基点平移+绕基点转动;vB=vA+vBA,ω 与基点无关。
速度投影定理
两点速度沿连线投影相等(刚体不变形);快算但给不出 ω。
速度瞬心 instantaneous center
该瞬时速度为零的点:垂线交点/纯滚动接触点;v=ω·d;两速度平行相等 → 瞬心无穷远(瞬时平移)。

动力学(第 9~12 课)

两类动力学问题
知运动求力(求导);知力求运动(解二阶 ODE,按 F 依赖 t/r/v 选积分法)。
动量定理 / 质心运动定理
dP/dt=ΣF外,P=Mvc;内力不改总动量;某方向外力零 → 该方向守恒(人船问题)。
动量矩 / 转动惯量
Lo=r×mv;定轴刚体 Lz=Jzω,Jz=Σmr²(杆端 mL²/3、盘 mR²/2)。
动量矩定理 / 定轴转动微分方程
dLo/dt=ΣMo(固定点/质心);Jzα=ΣMz;外力矩零 → 守恒(收臂加速)。
平行轴定理 / 回转半径
Jz=JC+Md²(一根轴必须过质心);J=Mρ²。
功与动能清单
功:mgh、½k(x₁²−x₂²)、Mφ、滑动摩擦 −Fs;动能:½Mv²、½Jω²、½Mvc²+½JCω²(柯尼希)。
动能定理 / 功率方程
T₂−T₁=ΣW(标量方程,理想约束零功);dT/dt=ΣP。
三大定理选用策略
求速度→动能;求力→动量/质心;转动→动量矩;碰撞冲量→积分形式。
惯性力 / 动静法
FI=−ma(虚构,无施力物体);加惯性力后按平衡解动力学,求动反力(转子动平衡依据)。
虚位移 / 虚功原理
约束允许的假想位移;理想约束下平衡 ⟺ ΣδW主动=0;约束力不出场,一步求平衡;通向拉格朗日力学。

专题篇(第 13~18 课)

惯性系/非惯性系
牛顿定律对惯性系成立;非惯性系补惯性力:平移 −ma_e,转动加离心与科氏项。
相对平衡
ΣF+F_Ie=0;旋转液面抛物面 z=ω²r²/2g。
碰撞冲量/恢复系数
只记碰撞冲量、位置冻结;e=|分离|/|接近|;ΔT=[m₁m₂/2(m₁+m₂)](1−e²)(v₁−v₂)²。
撞击中心
h=Jz/(ma):定轴刚体受撞此处轴承零碰撞反力。
平面运动微分方程
maC=ΣF、JC·α=ΣMC;纯滚 aC=g·sinθ/(1+J/mR²),只看分布比值。
密歇尔斯基方程/火箭方程
M·dv/dt=F外+u·(dM/dt);P=u|dM/dt|;Δv=u·ln(M₀/M末)。
自由度/广义坐标/广义力
独立参数个数;δW=ΣQj·δqj 的系数 Qj(保守系 −∂V/∂qj)。
拉格朗日方程
d/dt(∂L/∂q̇j)−∂L/∂qj=Qj,L=T−V;理想约束力自动消去。
循环坐标/能量积分
L 不含 q → 广义动量守恒;L 不显含 t → T+V 守恒;对称性给守恒律。
哈密顿函数/正则方程
H(q,p)=Σp·q̇−L;q̇=∂H/∂p、ṗ=−∂H/∂q;相空间中的现代力学。
