# 第 1 课 · 静力学公理与受力分析

> [!important] 受力图四步法(全课程地基)
> **取隔离体 → 画主动力 → 逐处补约束力 → 检查**。
> 解除几处约束,就在几处补约束力;方向由约束类型决定。

## 五公理

二力平衡(等值反向共线)· 加减平衡力系 · 平行四边形 · 作用反作用 · 刚化原理

## 六种约束与约束力

| 约束 | 约束力 |
| --- | --- |
| 柔索 | 沿索背离物体(只能拉) |
| 光滑面 | 沿公法线指向物体 |
| 固定铰 | **两个正交分量** Fx、Fy |
| 活动铰(滚动支座) | 垂直支承面、过铰心,1 个 |
| 二力杆 | 沿两铰连线,等值反向 |
| 固定端 | Fx + Fy + 力偶 M(3 个) |

> [!warning] 陷阱
> 铰链方向未知 → 画两分量,不许画单斜箭头;
> 二力杆三条件:两端受力、自重不计、平衡。

> [!tip] 衔接流体力学
> 流体微元的受力分析 = 同一套动作:质量力(重力)+ 表面力(压强/黏性)→ 分方向写平衡。
