# 理论力学 · 学习路线图

## 🗺️ 一图总览

![[路线图.drawio.png]]

> 流程图源文件:[[路线图.drawio]](可用 draw.io 打开继续编辑)。
> 蓝=静力学 · 橙=运动学 · 绿=动力学 · 黄菱形=能力验收门(不达标回炉)。

> [!important] 总目标(唯一验收标准)
> 为整个力学体系打好地基:任意构件会画受力图、任意力系会求平衡、
> 机构运动会说清楚、动力学三大定理能综合运用,并为流体力学与分析力学留好接口。
> **无外部考试**,验收全部走能力门——门不过不进下一阶段。

## 📋 课程结构(对应哈工大《理论力学》I 册主线 + II 册专题)

| 篇章 | 课程 | 训练的核心能力 |
| --- | --- | --- |
| **P1 静力学** | 第1课 公理与受力分析 · 第2课 汇交力系与力偶 · 第3课 平面任意力系 · 第4课 摩擦 | 画受力图、力系简化与平衡方程、自锁判断 |
| **P2 运动学** | 第5课 点的运动学 · 第6课 刚体基本运动 · 第7课 点的合成运动 · 第8课 刚体平面运动 | 自然法、速度合成、瞬心法 |
| **P3 动力学** | 第9课 质点与动量定理 · 第10课 动量矩定理 · 第11课 动能定理 · 第12课 达朗贝尔与虚位移 | 三大定理综合、动静法、虚功原理 |
| **P5 专题篇** | 第13课 非惯性系 · 第14课 碰撞 · 第15课 刚体平面运动动力学 · 第16课 变质量 · 第17~18课 分析力学 | 惯性力、恢复系数、拉格朗日方程、哈密顿视角 |

## 🗺️ 阶段规划(全部课程已产出,勾选 = 已出课)

### P1 静力学(✅ 已产出,待学)

- [x] 第 1 课 · 静力学公理与受力分析(五种约束、受力图;配约束演示)
- [x] 第 2 课 · 平面汇交力系与力偶(解析法、力偶性质、力线平移)
- [x] 第 3 课 · 平面任意力系(简化主矢主矩、平衡方程、物系平衡)
- [x] 第 4 课 · 摩擦(库仑定律、摩擦角与自锁、滚动摩阻)

**验收 M1**:任给物系 10 分钟内画出正确受力图;平面任意力系平衡题 5 题全对。
不达标 → 回炉第 1 课受力图步骤与第 3 课解题流程。

### P2 运动学(✅ 已产出,待学)

- [x] 第 5 课 · 点的运动学(矢量/直角坐标/自然法;aτ 与 an 分工)
- [x] 第 6 课 · 刚体基本运动(平移、定轴转动、传动比)
- [x] 第 7 课 · 点的合成运动(速度合成定理、科氏加速度;配速度合成演示)
- [x] 第 8 课 · 刚体平面运动(基点法、速度投影、瞬心法)

**验收 M2**:同一道平面机构题,速度合成法与瞬心法结果互验一致;科氏加速度方向判断 5 题全对。
不达标 → 回炉第 7 课动系选择原则与第 8 课瞬心求法。

### P3 动力学(✅ 已产出,待学)

- [x] 第 9 课 · 质点动力学与动量定理(两类问题、质心运动定理)
- [x] 第 10 课 · 动量矩定理(定轴转动微分方程、转动惯量、平行轴定理)
- [x] 第 11 课 · 动能定理(功与动能、理想约束、三定理选用策略)
- [x] 第 12 课 · 达朗贝尔原理与虚位移(动静法、虚功原理)

**验收 M3**:轮-绳-块类三大定理综合题独立完成;说明每个定理"什么时候选它"。
不达标 → 回炉第 11 课的选用策略表,重做对应错题。

### P4 收官与衔接(✅ 已产出,待学)

**验收 M4**:同一道题分别用牛顿法与动静法(或虚功原理)求解并互验;写一段"理论力学如何接入流体力学"的小结(受力分析→微元受力,动量定理→积分动量方程)。

## ⚙️ 配速(自定节奏,无考试锚点)

| 节奏 | 安排 |
| --- | --- |
| 建议 | 每周 2~3 课,与流体力学课**交替**进行(本周力学、下周流体的节奏亦可) |
| 每课动作 | 读手册该课 → 课内测验 → Obsidian 做该课习题集 → `status` 改 `learning`/`done` |
| 阶段末 | 做对应验收门,不过回炉;过了在 NOTES.md 记一笔 |
