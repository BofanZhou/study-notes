数学建模是什么？What is mathematical modeling?

🎯 本课目标

学完本课(约 15 分钟),你将能够:① 用一句话说清「建模」在干什么;② 以人口预测为例,亲手走通一次完整的建模闭环(假设→建立→求解→检验→修正);③ 说出国赛赛制要点,并知道你的十天冲刺地图在哪。

建模,就是「翻译」

现实问题不会自己长成方程。数学建模(mathematical modeling)做的事是:把现实翻译成数学(方程、规划、统计模型),求解之后,再把数学答案翻译回现实——并对现实说话。

一句话认识国赛:3 人、约 3 天(74 小时)、ABC 三题任选一、交一篇论文。评审盯的是四条:假设的合理性、建模的创造性、结果的正确性、表述的清晰性——注意,没有一条是「模型越高级越好」。

建模闭环:六个环节,一个循环

  1. 明确问题:决策变量是什么?目标是什么?约束是什么?
  2. 模型假设:抓主要矛盾,把次要因素先砍掉,逐条写下你砍了什么。
  3. 模型建立:把假设翻译成方程 / 规划 / 统计结构。
  4. 模型求解:解析解、数值解或编程计算。
  5. 模型检验:拿数据算残差、做灵敏度分析、用常识审问结果。
  6. 应用成文:回答最初的问题,写清楚假设的代价。
检验不达标?回到第 2 步修正假设——闭环的意义就在这里:模型是迭代出来的,不是一次写对的。

走一遍:预测人口(1790 → 2050)

问题:美国自 1790 年起每 10 年一次人口普查。用历史数据建模,预测未来人口。这是最经典的入门案例(Pearl & Reed, 1920),也是国赛 C 题气质的缩影:给数据 → 建模 → 预测 → 检验。

第一轮:指数模型(Malthus, 1798)

假设:单位时间人口的相对增长率为常数 r(出生多、死亡少,净增速率不变)。

dP/dt = rP　⟹　P(t) = P₀·ert

短期看相当准。但指数函数的宿命是爆炸——放到两百年尺度上,它必然脱离现实。怎么发现?靠检验。拖动下面的滑块试试:灰色虚线(指数模型)无论怎么调 r,残差平方和(SSE)都压不下去——这一步叫「检验不达标,回炉假设」。

第二轮:修正假设 → Logistic 模型

哪里错了?「增长率恒定」这个假设。人口越多,资源越紧张,增长率应该随规模递减。最简单的刻画:让增长率线性下降,到容量 K(环境容纳量,carrying capacity)时归零:

dP/dt = rP(1 − P/K)　⟹　P(t) = K / (1 + A·e−rt),A = (K−P₀)/P₀

这就是 Logistic(阻滞增长)模型:S 形曲线,前期近似指数增长,后期被 K 压住。Pearl 与 Reed 用 1790–1910 的数据拟合出 r≈0.031、K≈1.97 亿,预测 1930 年人口 1.231 亿,实际 1.228 亿,误差仅 0.24%——教科书级的成功检验。

但故事没完:20 世纪后期,真实人口越过了 1.97 亿仍在增长。为什么?K 并非常数——农业与医疗技术抬高了容纳量。于是再次回炉假设、改进模型。闭环永远转下去,这正是建模的诚实之处。

⚠️ 常见误区

①「模型越复杂越好」✗ 评审第一条是假设合理性;简单模型 + 完整闭环,胜过大模型黑箱。
②「一次就建对」✗ 检验不达标回炉是常态,论文里写明迭代过程反而加分。
③「拟合得好 = 模型对」✗ 还要外推检验与灵敏度分析——参数微调,结论稳不稳?

🔗 连接你已有的知识

这套闭环你在流体力学里见过:连续介质假设 = 模型假设;N-S 方程 = 模型建立;数值解 = 模型求解;与实验对比 = 模型检验。概统在学的最小二乘,就是今天「检验」环节的数学引擎。

Logistic 的亲戚遍布建环专业:牛顿冷却 dT/dt = −k(T − T室温)(房间温度趋近空调设定值)、传染病 SIR、新产品市场扩散——换壳不换芯。

线性规划 Linear Programming

🎯 本课目标

学完本课(约 20 分钟),你将能够:① 把「生产/配比/分配」类问题翻译成标准 LP 三要素(决策变量、目标函数、约束);② 用图解法理解「最优必在顶点」;③ 用 scipy.optimize.linprog 一步求解。

为什么它是国赛第一模型族

大量赛题的本质都是:资源有限,如何分配,使收益最大或成本最小。只要目标与约束都能写成决策变量的线性函数,它就是线性规划。第 2–3 课(优化族)值得你花掉备赛时间的最大头。

三要素与标准形式

  1. 决策变量(decision variables):你要决定的量,如两种产品的产量 x, y;
  2. 目标函数(objective):max z = 5x + 4y;
  3. 约束条件(constraints):资源/工时/需求,如 2x + y ≤ 50, x + 2y ≤ 60, y ≤ 15, x, y ≥ 0。
max cTx　s.t.　Ax ≤ b,　x ≥ 0

写模型时先把变量和单位写清楚,再一条条列约束——评审第一条看的就是这一步是否严谨。

图解法:为什么最优在顶点

把每条约束画成半平面,交集是一个凸多边形(可行域,feasible region)。目标函数的等值线 z = 5x + 4y 是一族平行直线:z 越大直线越远离原点。当等值线即将离开可行域的那一刻,接触的必然是一个顶点——这就是「最优在顶点」定理,也是单纯形法的全部直觉。

编程求解:scipy.optimize.linprog

from scipy.optimize import linprog
# linprog 默认求最小值,故目标取负:max 5x+4y → min -5x-4y
c = [-5, -4]
A = [[2, 1], [1, 2], [0, 1]]     # 左端系数
b = [50, 60, 15]                 # 右端上限
res = linprog(c, A_ub=A, b_ub=b, bounds=[(0, None), (0, None)])
print(res.x, -res.fun)           # x=[17.5, 15.], z=147.5

记住两个对应关系:≤ 约束 → A_ub/b_ub;min → max 取负号。等式约束用 A_eq/b_eq。

⚠️ 常见误区

① 约束方向写反——「至少」「不超过」要逐句核对,这是 LP 代码第一大 bug 源。
② 忘了 linprog 是 min——忘记取负号会得到「最优在原点」的可疑结果。
③ 把 LP 解当最终答案——产量可以切割到 17.5 台吗?变量该整数时,请进第 3 课。

🔗 连接你已有的知识

约束组 Ax ≤ b 就是矩阵语言——你在线性代数工作区学的矩阵乘法在这里落地。「最优在顶点 + 顶点由约束交出」也解释了为什么解对约束参数敏感:约束变一变,顶点就搬家——这正是论文里灵敏度分析的入口(影子价格 shadow price 我们在全真模拟前补讲)。

整数规划 Integer Programming

🎯 本课目标

学完本课(约 20 分钟),你将能够:① 一眼识别「变量必须取整数」的场景;② 解释为什么对 LP 解四舍五入是错的;③ 会用 scipy.optimize.milp 求解整数/0-1 规划,并用 0-1 变量表达「选/不选」。

什么时候必须整数

人数、设备台数、选址(建/不建)、开关(投/不投)——这些量取 17.5 没有意义。整数规划(integer programming, IP)就是给 LP 加上整数要求;变量只取 0 或 1 时叫 0-1 规划(binary programming),是国赛 B 题的常客。

四舍五入为什么是错的

回到第 2 课的例子:max z = 5x + 4y,LP 最优在顶点 (17.5, 15)。四舍五入到 (18, 15)?——违反约束 2x + y ≤ 50(2×18+15=51),根本不可行。而真正的整数最优是 (18, 14),z=146,比 LP 上界 147.5 损失 1.5。

两个教训:① 取整可能不可行,② 取整可能次优。整数最优必须用算法找,不能手工凑。

分支定界:一分钟的直觉

求解器用的主力算法是分支定界(branch and bound):先解 LP 松弛(不管整数要求)得到一个上界;若解非整数(如 x=17.5),就分成两支:x ≤ 17 和 x ≥ 18,各再解 LP……同时用当前最好整数解剪掉不可能更优的分支。理解它,你就能回答评审的追问:「为什么这个解是全局最优?」

scipy.optimize.milp 与 0-1 变量

from scipy.optimize import milp, LinearConstraint, Bounds
# 例:5 个候选站选 3 个(0-1),最小化建设成本
c = [12, 8, 15, 9, 11]                    # 各站成本
A = [[1,1,1,1,1]]                          # 总数恰好 3 个
res = milp(c=c, constraints=[LinearConstraint(A, 3, 3)],
           integrality=[1,1,1,1,1],        # 1 表示该变量必须整数
           bounds=Bounds(0, 1))            # 0-1 变量

建模技巧「大 M 法」:想表达「只有选了站 i( yᵢ=1 )才允许在那里建容量 xᵢ」,写 xᵢ ≤ M·yᵢ。逻辑约束(至少建两个、A 建则 B 不建)都能用 0-1 变量的线性组合写出来。

⚠️ 常见误区

① 对 LP 解取整——本课刚反例过:不可行或次优。
② 0-1 变量当成 0~1 连续变量——integrality 忘了设,求解器当 LP 处理。
③ 变量越多越稳——整数规划是 NP-hard,几百个整数变量加烂约束就可能算不动;先精简变量与约束。

🔗 连接你已有的知识

第 2 课的顶点直觉仍然成立,只是可行域从连续多边形变成离散格点——所以最优可能「够不到」顶点。检验环节新增一招:把 LP 松弛解当作上界基准,整数解离上界越近,说明解的质量越好(论文里可以报告这个间隙 gap)。

评价类方法 AHP & TOPSIS

🎯 本课目标

学完本课(约 20 分钟),你将能够:① 搭出「指标体系 → 标准化 → 定权 → 聚合 → 检验」的评价全流程;② 会用 AHP 定主观权重并通过一致性检验;③ 会用 TOPSIS 与熵权法,并能对「排序随权重变化」做灵敏度辩护。

评价题长什么样

「对四种冷热源方案排序」「对城市宜居性打分」「选哪种修复技术」——没有唯一解析解,只有合理可辩护的排序。国赛评价题(常在 C 题)的得分点不在用了哪个模型,而在每一步都有依据。

全流程五步

  1. 指标体系:从问题里选 4–8 个可量化指标(别堆几十个凑数);
  2. 标准化(normalization):把「越大越好/越小越好」统一成同向,常用极差法;
  3. 定权:AHP(主观)、熵权法(客观)、或两者组合;
  4. 聚合:加权求和,或更稳的 TOPSIS;
  5. 检验:AHP 做一致性检验;整体做权重灵敏度分析——权重挪一挪,排序稳不稳?

AHP:两两比较定权重

层次分析法(Analytic Hierarchy Process):对同一层的指标两两比较(1–9 标度:「同样重要」到「极端重要」),得到判断矩阵,取其最大特征值对应的特征向量归一化为权重。关键是一致性检验:要求判断不出现「A>B, B>C, 却 C>A」。

CI = (λmax − n)/(n − 1),　CR = CI / RI < 0.1 才通过

RI 是随机一致性指标查表值(n=3 时 0.58,n=4 时 0.90,n=5 时 1.12)。CR 不过关就回去调判断矩阵——论文里要写明这个过程。

TOPSIS:离理想解有多近

优劣解距离法(TOPSIS):标准化并加权后,每个指标取所有方案中的最好值拼成正理想解,最差值拼成负理想解;计算每个方案到两者的距离,贴近度越大越优:

Ci = Di− / (Di+ + Di−)

熵权法(entropy weight)则用数据自身的离散度定权:某指标各方案取值越接近(信息熵越大),区分度越低,权重越小。与 AHP 组合成「主客观组合权重」是论文常用加分项。

⚠️ 常见误区

① 忘了同趋势化——成本是负向指标,不翻直接算,「越贵越好」;
② 权重拍脑袋——评审必问「权重怎么来的」;AHP 要给判断矩阵,熵权要给数据依据;
③ CR ≥ 0.1 还硬用——宁可重调矩阵,不可硬着头皮上;
④ 把 TOPSIS 分当客观真理——它完全依赖权重,灵敏度分析才是你的辩护武器。

🔗 连接你已有的知识

熵权法的「离散度定权」就是概统里方差/信息量的直觉;标准化与你正在学的 z-score 是一回事。建环专业的方案比选(冷热源、风机选型、围护结构改造优先级)就是评价题的原型——上面演示里的方案就是按你的专业挑的。

预测类方法 Regression & Forecasting

🎯 本课目标

学完本课(约 20 分钟),你将能够:① 会做线性/多项式回归并读懂 SSE 与 R²;② 说出 R² 高不等于模型对(过拟合);③ 知道时间序列与灰色 GM(1,1) 各自的适用场景;能把「外推检验」变成默认动作。

预测题的三种武器

武器适用场景关键检验
回归分析(本课主力)有解释变量、样本较充足残差诊断 + R² + 外推检验
时间序列(移动平均/指数平滑/ARIMA)只有历史序列、有趋势或季节性留出后段做回测
灰色 GM(1,1)小样本、近似指数增长的数据后验差比 C 与小误差概率 p

最小二乘回归:一条直线的自我修养

给定点 (xᵢ, yᵢ),选直线 ŷ = a + bx 使残差平方和最小——这正是第 1 课检验环节的引擎:

min Σ(yᵢ − ŷᵢ)²,　R² = 1 − SSres/SStot

Python 里 numpy.polyfit 或 scipy.optimize.curve_fit(可拟合任意曲线,比如第 1 课的 Logistic)一步完成。残差要看图:随机散布=模型没漏东西;有弯曲趋势=该换曲线了。

R² 陷阱与过拟合

把阶数从 1 提到 3,训练集 R² 几乎必然上升——但曲线两端开始「翘飞」,对新数据反而更差。这叫过拟合(overfitting):模型背下了噪声,而不是学到了规律。对策很简单:留出最后 20% 数据不参与拟合,用它们验证预测力(外推检验);模型选择上宁可简洁。

GM(1,1):小样本时的灰色武器

数据只有七八个点、又近似指数增长时,经典操作是灰色预测:对原始序列做累加生成(AGO)让规律显形,再拟合白化微分方程 dx/dt + a·x = b,最后累减还原。报告结果时必须附后验差比 C = S₂/S₁(C<0.35 好)与小误差概率 p(p>0.95 好)——不附检验的 GM(1,1) 是评审最容易扣分的地方。

⚠️ 常见误区

① 把外推当可靠——预测超出数据范围越远越虚,要说明置信衰减;
② R² 高 = 模型对——过拟合随时恭候,要看外推与残差;
③ 小样本硬上深度学习——几十个数据点,回归/灰色/指数平滑才是正路;
④ 预测完不检验——回测(用前段预测后段)是预测题的标配动作。

微分方程模型 Differential Equation Models

🎯 本课目标

学完本课(约 20 分钟),你将能够:① 用「变化率 = 流入 − 流出」套路把机理问题写成 ODE;② 用 SIR 模型理解阈值(R0)与防控目标;③ 会用 scipy.integrate.solve_ivp 数值求解并说明「数值解够用」。

机理建模的万能套路

当问题有明确的物理/生物/经济机理时,不再从数据拟合出发,而是直接写平衡式:

某量的变化率 = 流入速率 − 流出速率

人口增长(出生率−死亡率)、房间温度(得热−散热)、库存(进货−消耗)、疫情(新感染−恢复)——全是这个套路的换装。你在流体力学学的连续性方程,就是它最恢弘的版本。

SIR:传染病模型的教科书

把人群分成易感(Susceptible)、感染(Infectious)、移出(Removed)三类:

dS/dt = −βSI/N,　dI/dt = βSI/N − γI,　dR/dt = γI

核心量是基本再生数 R0 = β/γ:一个感染者在全易感人群中平均传染的人数。R0 > 1 疫情爆发,R0 < 1 自然消退——这就是阈值效应,也是防控建模的意义(把有效再生数压到 1 以下)。

数值解:为什么够用

大多数 ODE(尤其非线性组)没有初等解析解。工程上的标准做法是数值积分:把时间切成小步,按导数逐步外推(Euler 的思想),scipy.integrate.solve_ivp 内置自适应高阶方法,精度远超手工 Euler。论文里写明:方法(RK45)、步长控制、初值与参数来源——就完整了。

from scipy.integrate import solve_ivp
def sir(t, y, beta, gamma, N):
    S, I, R = y
    return [-beta*S*I/N, beta*S*I/N - gamma*I, gamma*I]
sol = solve_ivp(sir, [0, 120], [990, 10, 0],
                args=(0.3, 0.1, 1000), dense_output=True)

参数从哪来 + 平衡点分析

参数 β、γ 两个来源:文献引用(注明出处)或数据拟合(第 5 课的 curve_fit 套在 ODE 解外面)。进阶动作:令所有导数为零解出平衡点(如地方病平衡点 S* = γN/β),并说明解从哪边趋近它——这一小节写进论文,就是「建模的创造性」的直接证据。

⚠️ 常见误区

① 参数拍脑袋——β=0.3 必须有出处或拟合依据,评审必问;
② 只画曲线不做分析——峰值、到达时间、平衡点、灵敏度至少做两样;
③ 死磕解析解——非线性模型数值解 + 检验完全够,别浪费 74 小时里的 10 小时;
④ 单位不统一——β 的单位是 1/天还是 1/小时,算错量纲全盘皆输。

🔗 连接你已有的知识

这就是你流力学了三课的那条路:连续介质假设 → 建立方程 → 数值求解 → 与数据对比——CFD 本身就是大型 ODE/PDE 建模。建环课里的房间逐时温度、CO₂ 浓度积分方程,与 SIR 同属一族。第 1 课的 Logistic 与牛顿冷却,则是本课的一维特例。

摘要五句式

  1. 做了什么问题:针对……问题(一句);
  2. 关键假设/数据处理:针对……,考虑到……,建立了……;
  3. 方法主线:采用……方法求解(一以贯之的主线,不罗列);
  4. 结果带数字:求得……为 XX(误差/增益 XX%),没有数字的摘要等于没写;
  5. 亮点与检验:模型经灵敏度/回测检验,结论稳健。
反例:「本文建立了多种模型,运用了大量算法,取得了良好的效果。」——零信息。
正例:「针对负荷预测,建立 Logistic 阻滞增长模型,curve_fit 拟合得 K=331.5(残差 2.1%),回测 2020 年误差 1.8%,灵敏度分析显示 ±10% 参数扰动下结论不变。」

环境容纳量carrying capacity (K)资源约束下系统规模的上限;Logistic 中 K 的物理含义。
内禀增长率intrinsic growth rate (r)资源不受限时的固有增长率,对应曲线早期斜率。
外推extrapolation把模型用到数据范围之外做预测;翻车高发区,必须谨慎并说明理由。
灵敏度分析sensitivity analysis轻微扰动假设/参数,看结论动不动;检验结论是否稳的一种手段。
国赛(CUMCM)China Undergraduate Mathematical Contest in Modeling全国大学生数学建模竞赛:3 人、约 3 天、ABC 三题选一,交一篇论文。
线性规划linear programming线性目标 + 线性约束下求最优分配;最优必在顶点。
可行域feasible region全部约束的交集,凸多边形/凸多面体。
影子价格shadow price约束右端每放松一单位,目标改善多少;灵敏度分析的入口。
整数规划integer programmingLP + 整数要求;LP 解四舍五入不可靠。
0-1 规划binary programming变量只取 0/1,表达「选/不选」与逻辑约束。
分支定界branch and boundLP 松弛给界 + 分支搜索 + 剪枝,求全局整数最优。
大 M 法big-M methodx ≤ M·y 把「选了才能建」翻译成线性约束。
层次分析法AHP两两比较得判断矩阵 → 特征向量定权重。
一致性比率consistency ratio (CR)CR = CI/RI < 0.1 才算判断不自相矛盾。
优劣解距离法TOPSIS贴近度 = 到负理想距离 / 到两理想距离之和。
熵权法entropy weight数据区分度大 → 权重大;客观定权。
决定系数coefficient of determination (R²)模型解释的波动比例;高 ≠ 模型对。
过拟合overfitting背下噪声而非规律;外推检验是照妖镜。
时间序列time series只用历史序列预测未来(移动平均/指数平滑/ARIMA)。
灰色预测GM(1,1)小样本准指数:累加生成 + 白化方程,须附后验差检验。
机理建模mechanistic modeling变化率 = 流入 − 流出;与数据拟合互补。
SIR 模型SIR model易感/感染/移出三仓室的传染病微分方程组。
基本再生数basic reproduction number (R0)一个感染者平均传染人数;R0=1 是爆发阈值。
平衡点equilibrium导数为零的定态,回答系统长期走向。
