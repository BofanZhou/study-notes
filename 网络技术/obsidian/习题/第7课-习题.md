# 第 7 课 习题 · 网络层进阶:ARP、ICMP、NAT 与路由

## 一、基础题(≥8)

> [!question]- 1.1 ARP 的作用与工作过程?
> **答案**:同网段内由 IP 求 MAC。主机广播 ARP 请求(含目标 IP),目标主机单播应答自己的 MAC;双方将映射写入 ARP 缓存,超时老化。

> [!question]- 1.2 主机发现目的 IP 不在同一网段时,帧的目的 MAC 填什么?IP 头的目的地址填什么?
> **答案**:MAC 填默认网关(路由器接口);IP 头仍是真正的目的主机——"MAC 逐段变,IP 端到端不变"。

> [!question]- 1.3 ICMP 报文分哪两类?各举一例。
> **答案**:询问类(回送请求/应答)与差错报告类(终点不可达、超时、参数问题、改变路由)。

> [!question]- 1.4 ping 与 traceroute 分别利用了 ICMP 的什么机制?
> **答案**:ping=回送请求/应答测连通与时延;traceroute 把 TTL 从 1 逐次加 1,靠沿途路由器返回的"超时"报文记录每一跳。

> [!question]- 1.5 对比 RIP 与 OSPF(算法、度量、承载、规模)。
> **答案**:RIP:距离向量、跳数(≤15)、UDP 520、小网;OSPF:链路状态+Dijkstra、开销(带宽)、IP 89、大中型网、收敛快。

> [!question]- 1.6 BGP 用于什么位置?它追求"最优路径"吗?
> **答案**:自治系统(AS)之间(EGP,TCP 179);追求"可达 + 符合策略"的合理路径而非数学最优——策略优先。

> [!question]- 1.7 NAT/NAPT 的工作原理一句话?它带来什么副作用?
> **答案**:路由器按"(内网IP:端口)→(公网IP:端口)"映射表改写地址端口(端口区分连接);副作用:外网无法主动访问内网(破坏端到端,需端口映射)。

> [!question]- 1.8 IPv6 地址多少位?零压缩 `::` 的使用规则?
> **答案**:128 位,冒号十六进制;每组前导 0 可省,连续全 0 组可用 `::` 代替但**全地址只能出现一次**;过渡用双协议栈与隧道。

## 二、工程应用题(≥2)

> [!question]- 2.1 办公电脑 ping 网关通、ping 8.8.8.8 通、ping www.example.com 不通。问题最可能出在哪一环?用什么命令验证?
> **答案**:出口路由与链路都正常,卡在**域名解析**→ DNS 故障(配置错/DNS 服务宕)。用 `nslookup www.example.com` 验证;修法:改正确 DNS 地址或恢复 DNS 服务。

> [!question]- 2.2 家里新装 NAS 想让外网同事访问,直接访问 192.168.1.50 失败。为什么?给出两种可行做法。
> **答案**:192.168.1.50 是 NAT 后的私有地址,公网不可路由。做法:① 在路由器上做端口映射(NAT 虚拟服务器,公网:端口 → 192.168.1.50:端口);② 内网穿透/专用 VPN;正规企业则申请公网地址或域名+VPN。

## 三、开放思考题(1)

> [!question]- 3.1 IPv6 全面普及后,NAT 会消失吗?
> **答案**:开放思考。要点:地址充足后 NAT 的"省地址"使命结束,端到端透明性回归;但 NAT 的"副作用"(内网天然不暴露)被当成了安全手段,家用路由仍会保留地址转换/隔离功能;企业还会用 NPTv6、防火墙等替代。技术会退场,需求不会。

## 四、概念陷阱选择题(识别干扰项)

> [!question]- 4.1 ARP、ICMP、RIP 分别属于/使用哪个层次?
> **A.** 都在运输层 　**B.** ARP/ICMP 属网络层,RIP 是应用层协议(用 UDP)实现路由信息交换 　**C.** RIP 属网络层
> > [!success]- 答案
> > **B**。ARP/ICMP 是 TCP/IP 网际层;RIP 本身作为应用进程用 UDP 520 交换路由信息——"路由协议跑在应用层"是常考细节。

> [!question]- 4.2 关于 RIP,正确的是?
> **A.** 用带宽作为度量 　**B.** 最大跳数 15,16 表示不可达 　**C.** 用 Dijkstra 算法计算路径
> > [!success]- 答案
> > **B**。RIP 数跳数(≤15),16=无穷大;OSPF 才用带宽开销与 Dijkstra。

> [!question]- 4.3 地址 2001:db8::abc::1 是合法 IPv6 地址吗?
> **A.** 合法 　**B.** 不合法,:: 只能出现一次 　**C.** 合法,但必须全大写
> > [!success]- 答案
> > **B**。零压缩只能用一次,否则无法唯一还原零组的个数。
