# 第 4 课 · 物理层与传输介质

> [!important] 四大特性 + 两个公式
> 特性:**机械、电气、功能、规程**。
> 无噪声:**奈奎斯特** 2W·log₂V;有噪声:**香农** W·log₂(1+S/N);实际取小者。
> dB 换算:10dB=10 倍,20dB=100 倍,30dB=1000 倍。

## 介质速查

| 介质 | 要点 |
| --- | --- |
| 双绞线 | ≤100 m,局域网布线 |
| 光纤 | 全反射传光、抗干扰;**单模远、多模近**;传播速度与铜线相近(陷阱!) |
| 无线 | 微波视距直线;WiFi 2.4/5 GHz |

## 编码(选择题)

- **曼彻斯特**:每比特中间必跳变、自带同步(传统以太网);波特率 = 2×比特率
- 差分曼彻斯特:看比特**开始处**有无跳变(有=0 无=1)

## 复用

FDM 分频 / TDM 分时(统计 TDM 按需) / WDM 分波 / CDMA 分码

> [!warning] 陷阱
> 带宽加大 ≠ 传播时延缩短;光纤快的是**带宽**不是传播速度。
